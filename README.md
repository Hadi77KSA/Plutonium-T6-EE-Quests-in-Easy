# Plutonium-T6-EE-Quests-in-Easy
This mod allows the Easter Egg quests of BO2 to be accessible in Easy difficulty.

Install by placing the `scripts` folder in `%localappdata%\Plutonium\storage\t6`

## Notice for CO-OP
If you are going to join a party before starting the match, the host will have to have the difficulty set to **"original"**, especially for TranZit and Buried. The script will change the difficulty to easy by itself at the start of the match.
